# SkillHub 发布说明

本文件说明本项目的发布物、上架内容及验证方法。当前版本为 **2.0.1**，版本源为 [suite.json](../suite.json)。具体发布字段、包大小限制和审核规则以目标 SkillHub 当前页面为准；本项目未声称已经完成平台导入或审核。

## 上传哪个文件

在项目根目录运行：

```powershell
python -B -m unittest discover -s tests -v
python scripts/package_skill.py
```

上传 `dist/skillhub/hr-specialist-2.0.1.zip`。同目录的 `.zip.sha256` 用于核对文件，`.manifest.json` 用于核对版本和包内资源，不需要作为技能包上传。

ZIP 根目录直接放置 `SKILL.md`，附带 README、连接说明、13 个业务子技能、共享规则、脚本、模板、虚构样例和测试。保持该完整结构，避免二次压缩时增加一层项目文件夹，也不要只上传子技能目录。各子技能有共享依赖；当前发布物是一个完整套件。

SkillHub 已反馈无扩展名 `LICENSE` 不允许上传。构建工具将仓库的 `LICENSE` 原样导出为 `LICENSE.txt`，重写包内对应 Markdown 链接；ZIP 内不包含无扩展名文件。项目分发文件类型限 `.md/.txt/.json/.yaml/.py/.csv`，不代表这些类型已全部通过平台现场审核。

`suite.json` 是项目自身的技能清单，`agents/openai.yaml` 是可选宿主界面元数据，两者不宣称为所有 SkillHub 客户端通用的注册协议。客户端只识别一个入口时，从根 `SKILL.md` 路由；多技能菜单是否自动出现需在实际宿主验证。

## 发布包结构

项目采用三类资源分组：

- `skills/`、`references/`、`scripts/`、`agents/`：技能指令、执行工具及运行时依赖。
- `assets/catalog/`、`assets/configs/`、`assets/templates/`：场景注册表、默认禁用的配置示例和业务模板。
- `examples/local/`、`examples/queries/`、`tests/`、`docs/`：可复现样例、验证材料及发布说明。

打包采用显式白名单，不依赖工作区当前暂存状态，也不通过扫描整个仓库收集文件。隐藏文件、IDE、Git、真实连接配置、环境文件、输出和旧发布包不进入 ZIP。允许分发的配置只有包内指定的默认禁用示例。

## 自检与导入验证

1. **源码验证**：运行自动化测试；确认根入口和13个业务技能的frontmatter、版本及界面元数据一致。
2. **构建验证**：打包工具检查维护文件存在、路径位于项目内、Markdown本地链接被包含、SKILL.md为无BOM UTF-8，并生成ZIP和校验清单。
3. **独立验证**：将ZIP解压到一个新目录，从该目录运行相同测试和README中的虚构演示；原仓库之外也应能定位场景、样例及共享规则。
4. **实际导入**：在目标SkillHub中上传ZIP并按页面要求填写内容，查看平台实际解析结果和审核反馈。
5. **宿主验收**：安装后查询虚构假期余额；未配置连接时，真实查询应返回not_connected，而不是展示样例作为实际结果。随后由授权人员配置实际企业服务再验证权限。

完成前三项只能证明发布包的项目自检通过；第四、五项需要目标平台及客户端环境，尚未在本项目中验证。回归案例及现场验收点见 [验收说明](../references/acceptance.md)。

## 已知接入限制

正式业务查询只读，办理仅给入口；原生应用身份不能直接充当员工身份。浏览器OAuth需要目标宿主和企业平台配置，本项目不提供通用回调服务器。真实企业接口、模块授权、SkillHub审核及宿主菜单行为需要在目标环境验收。
