# HR专家套件验收说明

套件包含13项业务技能；内部HR共享规则为共用资源，不注册菜单，根入口负责路由。当前版本见suite.json。下列验证区分客户端能力、虚构样例与需要真实企业环境完成的联调。

## 交付覆盖

| 需求 | 实现 | 验证边界 |
|---|---|---|
| 数据查询 | 宿主自然语言选场景+102场景参数目录+确定性查询引擎 | 脚本不冒充独立大模型 |
| 员工档案 | 本人基本/任职/教育/技能/项目/履历/考核/证书/奖励/晋升等 | 源服务须提供对应模块 |
| 考勤休假 | 假期余额、打卡异常、排班、加班、公出、出差、休假和调休 | 保留单位与查询期间，不直接扣薪 |
| 组织架构 | 部门负责人/HRBP/领导/助理/层级与编制 | 明确管理用途、管理角色与部门权限 |
| 审批查询 | 本人待办/已办、在途/结束、节点与审批人 | 不审批或代提交 |
| 企业知识库 | 关键词/分类/时间检索及文档版本与来源 | 不把示例制度当企业政策 |
| 办事入口 | 服务菜单、可信链接和导航路径 | 不拼造链接、不声称已办理 |
| 招聘需求管理 | 状态/名称/编号/提出人、HC、负责人、到岗与进展 | 需求与职位分开 |
| 职位管理 | 检索、JD、职责、资格、人数、薪资脱敏、地点、申请量 | 有权负责职位范围 |
| 人才搜寻 | 岗位条件、推荐、批量分页、异步状态、有界轮询和操作入口 | 发起/取消仅系统入口，不正式操作 |
| 应聘者跟进 | 申请阶段、简历、面试、Offer、入职核对 | 人才/申请/职位不混同 |
| 招聘待办 | 我的筛选/评价/参加面试、今日和近期日程 | owner_subject_id与当前用户一致 |
| 招聘洞察 | 进展、卡点、重点岗位、阶段量、转化与分析入口 | 当前授权过滤范围，不从单页推全局 |
| 共享规则 | 租户/用户/角色/行级检查、白名单字段、敏感数据隐藏 | 后端必须先执行真实权限及字段分级 |

这些是已交付的客户端技能、场景契约与执行能力；不表示各厂商原生接口已经逐项接通。已连接系统的数据准确性、授权范围和模块开通情况由源系统及适配层负责。

## 自动验收

```powershell
python -B -m unittest discover -s tests -v
python scripts/package_skill.py
```

自动用例覆盖：13业务技能/102场景结构；每个登记场景的合法授权响应；本人、跨租户、组织部门、经理职位和招聘待办越权阻断；不接受本地身份覆盖；API Key缺失零网络；未连接/过期/403/模块未开通/空页/部分页/错误区分；密钥、常见证件薪资和联系方式隐藏；入口主机与凭据URL阻断；异步有界轮询及终态停止；已有本地计算回归；打包路径、BOM与固定文件清单。另有真实Python HTTP客户端与本机虚构网关的序列化契约测试，使用假密钥，不访问企业系统。

所有数据业务查询为GET，鉴权与查询响应都需契约验证；仅旧原生连接工具会POST应用授权请求。新查询/轮询没有业务写入调用。

## 用户快速上手场景

| 问法 | 场景 | 预期 |
|---|---|---|
| 帮我查下我有哪些待办审批 | approval.pending | 当前本人相关待办，保留节点/审批人 |
| 我上个月有没有迟到或忘记打卡 | attendance.exceptions | 2026-11-09按上海时区解析为2026-10-01至10-31 |
| 我还有几天年假 | attendance.annual_leave；演示用attendance.balance | 日期、余额与天/小时单位，不混淆 |
| 公积金提取政策是什么 | knowledge.search | 引用企业已授权文档的版本/来源，不用通用记忆编造 |
| 我负责的在招职位整体进展 | insight.overview | 负责职位和授权范围，披露统计口径 |
| 我今天有几场面试，几点 | todo.today_interviews | 按当前用户、当天日期、明确时区 |
| 找3至5年经验、本科、B端产品人才 | talent.search | 参数与岗位证据，分页保留，不声称本地完成AI推荐 |
| 继续轮询这个搜寻任务 | talent.job_status / poll | 显式有界轮询，过期或终态立即停止 |
| 帮我取消搜寻/发起面试分析 | talent.cancel_entry / insight.interview_quality_entry | 可信系统入口，无业务写入 |

`--demo`提供16组固定虚构样例，演示结果必有demo=true和提示；未有fixture的场景明确返回无演示模块，不能编造。没有真实连接时不自动用演示数据回答业务问题。

## 保留本地能力
