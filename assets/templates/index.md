# 模板目录

复制所需模板到用户指定的输出目录，不覆盖源模板。

| 任务 | 模板 |
|---|---|
| 招聘需求、JD、简历比对、面试、Offer | [recruitment.md](recruitment.md) |
| 入职、转正、调岗、离职、交接 | [lifecycle.md](lifecycle.md) |
| 绩效、培训、员工沟通、月报 | [people-operations.md](people-operations.md) |
| 员工台账空表 | [employees.csv](employees.csv) |
| 工资复核空表 | [payroll.csv](payroll.csv) |
| 绩效指标空表 | [performance.csv](performance.csv) |
| 可选服务禁用配置 | [connector.example.json](../configs/connector.example.json) |

CSV 表头与脚本一致，字段说明见 [数据口径](../../references/data-rules.md)。方括号为填写位置，不是示例事实；未发生事项保持待办理。
